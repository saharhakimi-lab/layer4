⚡ מה זה פורט ומה זה Socket?

פורט הוא מספר לוגי בין 0 ל-65535 שמזהה תוכנה או שירות ספציפי במחשב. כשמשלבים כתובת IP יחד עם מספר פורט למשל: 192.168.1.10:80, מקבלים נקודת קצה יחידה במינה שנקראת Socket!

🤝 פרוטוקול TCP - Transmission Control Protocol

⚡ אופן פעולה - אמינות מעל הכל!

TCP הוא פרוטוקול מוכוון חיבור Connection-Oriented. לפני שהוא שולח בייט אחד של דאטה, הוא יוצר קשר עם הצד השני, מוודא שהוא ערני ומוכן לקבל מידע. אם מקטע הלך לאיבוד בדרך - TCP מזהה זאת ומשדר אותו מחדש! מתאים ליישומים שבהם אסור לאבד אפילו ביט אחד (אתרי אינטרנט, העברות כספיות, קבצים, מיילים).

🛠️ מנגנוני הליבה של TCP

לחיצת יד משולשתSYN → SYN-ACK → ACK
אישור קבלה ACKAcknowledgment Number
בקרת עומסיםSliding Window Mechanism
סיום התקשרותFIN → ACK → FIN → ACK

טיפ מטורלל של השותפים

זוכרים את לחיצת היד? SYN "אחי אפשר לדבר?", SYN-ACK "כן אחי בכיף!", ACK "סגור, מתחילים לשלוח!". בלי 3 הצעדים האלה - אין תקשורת TCP!

סוג פרוטוקול:Connectionless
יחידת PDU:Datagram דאטאגרם
מהירות:Ultra Fast / Low Overhead
ערבות להגעה:Best-Effort - אין ACK

פרוטוקול UDP - User Datagram Protocol

⚡ אופן פעולה - מהירות שיא, אפס גינונים!

UDP הוא פרוטוקול ללא חיבור Connectionless. הוא לא מבצע לחיצת יד, לא מבקש אישורי קבלה ACK ולא משדר מחדש חבילות שנפלו. הוא פשוט יורה את הדאטאגרמות Datagrams לאוויר בשיא המהירות! מתאים ליישומים בזמן אמת שבהם מהירות חשובה יותר מכל פריים בודד שנשמט (משחקי רשת, שיחות זום/וידאו, שידורי לייב, DNS).

תכונות מפתח של UDP

Header קל משקל8 Bytes בלבד לעומת 20 ב-TCP
אפס השהיה Latencyאין לחיצת יד בתחילה
ללא Re-transmissionחבילה שנפלה - הלכה לבלי שוב
שימושים נפוציםVoIP, Streaming, Gaming, DNS
